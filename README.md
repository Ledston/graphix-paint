# GraphiX Paint

Программа для рисования в духе PaintTool SAI 2. В ней тот же нажим и стабилизатор, что в SAI, больше настроек кистей и слои как в Photoshop / Clip Studio. Есть деформация сеткой, пластика, кривые, PSD, лайнарт из любой картинки, заливка по лайнарту и таймлапс.

**Скачать для Windows 10/11 (64 бит):**
https://github.com/Ledston/graphix-paint/releases/latest/download/GraphiX-Paint-win64.zip

Распакуйте архив в любую папку (например, `Документы\GraphiX Paint`) и запустите `GraphiX.exe`. Установка не нужна. Если положить рядом с программой пустой файл `portable.txt`, все настройки и кисти будут храниться в папке программы. Так удобно носить её на флешке.

## Планшет (Huion и другие)

По умолчанию программа работает через **Wintab**, как SAI. Поэтому Windows Ink в драйвере планшета можно выключить.

Переключение находится в *Настройки → Ввод с пера*: Wintab или Windows Ink. Оно срабатывает сразу, перезапуск не нужен. Если драйвер Wintab не найден, программа сама работает через Windows Ink.

В *Настройки → Перо и планшет…* есть:
- общая кривая нажима с полем для проверки;
- порог слабого нажима;
- обратный конец пера как ластик;
- боковая кнопка как пипетка;
- нажим для мыши.

## Основное

| Что | Как |
|---|---|
| Двигать холст | Пробел + перетаскивание, средняя кнопка мыши |
| Масштаб | Ctrl + Пробел + перетаскивание, колесо мыши, Ctrl +/- |
| Повернуть холст | Alt + Пробел + перетаскивание, клавиши `-` / `=`, сброс — Backspace |
| Отразить вид | H |
| Проверка в ч/б | Ctrl+Shift+Y |
| Пипетка | Alt (удерживать) или правая кнопка |
| Размер кисти | Ctrl + Alt + перетаскивание, `[` и `]` |
| Ластик / кисть | E |
| Поменять цвета / сбросить | X / D |
| Переместить слой (или все выбранные) | Ctrl (удерживать) + перетаскивание, инструмент V |
| Трансформация / сетка / пластика | Ctrl+T / Ctrl+Shift+T / Ctrl+Shift+X |
| Сделать лайнарт | Ctrl+Shift+L |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |

**Все горячие клавиши настраиваются:** *Настройки → Горячие клавиши* (Ctrl+Alt+K). Там есть поиск и проверка конфликтов.

## Слои

- **Несколько слоёв сразу.**
  - Ctrl + щелчок добавляет слой к выбранным или убирает его.
  - Shift + щелчок выбирает все слои подряд.
  - Выбранные слои можно двигать, трансформировать, удалять, дублировать, объединять, складывать в папку и перетаскивать в списке. Видимость, непрозрачность и режим наложения меняются у всех сразу.
- **Двойной щелчок по слою** открывает его свойства. **F2** переименовывает слой.
- **Правый щелчок по слою** открывает меню со всем, что можно сделать со слоем:
  - создать слой;
  - дублировать, объединить, сложить в папку;
  - опорный слой, обтравка, сохранение прозрачности, закрепление, цвет метки;
  - быстрые эффекты;
  - каналы;
  - маска;
  - пиксели.
- **Каналы**:
  - хроматическая аберрация, включается и выключается одним щелчком;
  - альфа → выделение;
  - прозрачность → маска;
  - альфа-канал как слой;
  - инвертировать альфу;
  - разложить на красный, зелёный и синий слои;
  - убрать белый фон (для сканов);
  - перекрасить в основной цвет.
- **Эффекты слоя** не портят рисунок и меняются в любой момент:
  - обводка (гладкая);
  - тень и внутренняя тень;
  - внешнее и внутреннее свечение;
  - наложение цвета и градиента;
  - размытие;
  - текстура бумаги;
  - зерно (шум);
  - скринтон;
  - хроматическая аберрация.
- 30 режимов наложения, включая SAI Shine / Shade и «Затухание (шум)».
- Слои бывают пиксельные, линейные (векторные), текстовые, корректирующие и папки. Обтравку можно ставить и на папку.

## Лайнарт и покраска

- **Фильтр → Сделать лайнарт…** превращает любую картинку в настоящий лайнарт: линии на прозрачном слое, под которым можно красить. Есть живой предпросмотр.
  - Режимы: авто, фото, набросок / скан, аниме / рендер.
  - Настройки линий: детализация, толщина, плавность, удаление соринок, закрытие разрывов, цвет линий.
  - «Как от руки»: дрожание, нажим, вторая скетчевая линия, текстуры карандаша, угля и туши.
  - Готовые шаблоны.
  - Результат можно сделать редактируемым слоем линий.
- **Заливка по лайнарту.** Отметьте слой с линиями как *опорный* (правый щелчок → «Опорный слой»), у заливки выберите «Границы: опорные слои» и заливайте на слое под линиями. Настройки «Закрывать щели» и «Заходить под линии» убирают белые края.
- **Слой → Автозаливка цветами** заливает каждую замкнутую область лайнарта своим цветом на отдельном слое.

## Остальное

- **Кисти как в SAI**: плотность, жёсткость, смешивание, разбавление, удержание цвета, кайма, нажим на размер, плотность и смешивание.
  - Сверх SAI: форма кончика, наклон пера, разброс, сужение концов, аэрограф.
  - 14 готовых кистей, ячейки для своих кистей, экспорт и импорт.
- **Стабилизатор**: Среднее (1–15, как в SAI), Скорость (S-уровни), Верёвка, сглаживание нажима.
- **Текстуры как в SAI 2**: *Справка → Открыть папку текстур*. Внутри три папки:
  - `paper` — бумага;
  - `brush` — текстуры кисти;
  - `shapes` — формы кончика.

  Положите туда картинки и выберите *Справка → Перезагрузить текстуры*.
- **Коррекция**: кривые, уровни, яркость / контраст, тон / насыщенность, цветовой баланс, карта градиента и другие. Её можно применить к слою или сделать корректирующим слоем.
- **Фильтры**: размытие, контурная резкость, свечение, шум (с режимами наложения и размером зерна), пикселизация, скринтон.
- **Трансформация**: свободная, с перспективой и наклоном. Деформация сеткой, пластика.
- **Выделение**: прямоугольник, овал, лассо, волшебная палочка, кисть, цветовой диапазон.
- **Вид**:
  - сетка, правило третей, золотое сечение;
  - проверка в ч/б;
  - панель «Превью»: вся картинка целиком, с отражением;
  - гармонии цветов на панели «Цвет».
- **Таймлапс**: *Файл → Таймлапс → Записывать*, затем «Экспорт видео» в MP4.
- **Холст до 100000 x 100000**, несколько окон одного холста, восстановление работы после сбоя.
- **Форматы**:
  - `.gxp` — всё сохраняется;
  - PSD / PSB — слои, папки, маски, обтравка, режимы;
  - PNG, JPEG, BMP, TIFF, WebP.
- **Настройки** (меню *Настройки*): язык (русский / English), темы (тёмная, серая, светлая), размер значков, курсор, холст, перо, файлы, производительность.

## Сборка из исходников

Нужны Qt 6.8, CMake 3.21+ и компилятор C++20 (MSVC 2022). Готовая сборка делается автоматически через GitHub Actions (`.github/workflows/build.yml`).

```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=<путь к Qt>
cmake --build build
```
