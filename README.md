# GraphiX Paint

Программа для рисования в духе PaintTool SAI 2: тот же нажим и стабилизатор, больше настроек кистей,
слои как в Photoshop / Clip Studio, деформация сеткой, пластика, кривые и PSD.

**Скачать для Windows 10/11 (64 бит):**
https://github.com/Ledston/graphix-paint/releases/latest/download/GraphiX-Paint-win64.zip

Распакуйте архив в любую папку (например, `Документы\GraphiX Paint`) и запустите `GraphiX.exe`.
Установка не нужна. Если положить рядом с программой пустой файл `portable.txt`, все настройки
и кисти будут храниться в папке программы (удобно для флешки).

## Планшет (Huion и другие)

* По умолчанию используется **Windows Ink**: это лучший вариант для Huion Kamvas с актуальным драйвером.
  В драйвере Huion включите «Windows Ink» для GraphiX.exe (или глобально).
* Если нажим не работает, откройте *Правка > Настройки > Перо*, выберите **Wintab** и перезапустите программу.
* Там же: общая кривая нажима (с полем для проверки), нажим для мыши, правая кнопка / кнопка пера как пипетка.
* Удержание пера (правый щелчок Windows), «круги» при касании и жесты Windows на холсте отключены.

## Основное

| Что | Как |
|---|---|
| Двигать холст | Пробел + перетаскивание, средняя кнопка |
| Масштаб | Ctrl + Пробел + перетаскивание, колесо мыши, Ctrl +/- |
| Повернуть холст | Alt + Пробел + перетаскивание, клавиши `-` / `=`, сброс Backspace |
| Отразить вид | H |
| Пипетка | Alt (удерживать) или правая кнопка |
| Размер кисти | Ctrl + Alt + перетаскивание, `[` и `]` |
| Ластик / кисть | E |
| Поменять цвета / сбросить | X / D |
| Переместить слой | Ctrl (удерживать) + перетаскивание, инструмент V |
| Трансформация / сетка / пластика | Ctrl+T / Ctrl+Shift+T / Ctrl+Shift+X |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |

**Все горячие клавиши настраиваются:** *Правка > Горячие клавиши* (Ctrl+Alt+K), с поиском и проверкой конфликтов.

## Возможности

* **Кисти как в SAI**: плотность, жёсткость, смешивание, разбавление, удержание цвета, кайма, мин. размер и плотность,
  интервал, нажим на размер/плотность/смешивание, своя кривая нажима для каждой кисти.
  Сверх SAI: форма кончика, угол (по штриху или по наклону пера), разброс размера/угла/цвета, рассеивание,
  сужение в начале и конце, накопление (аэрограф), распыление на месте, сохранение прозрачности.
  14 готовых кистей, свои кисти в ячейках, экспорт и импорт кистей (`.gxbrush`).
* **Стабилизатор**: Среднее (уровни 1–15 как в SAI), Скорость (S-уровни), Верёвка; отдельное сглаживание нажима.
* **Текстуры как в SAI 2.** Папка открывается через *Справка > Открыть папку текстур*:
  * `paper` — текстуры бумаги (для кисти и для эффекта слоя «Текстура бумаги»),
  * `brush` — текстуры кисти,
  * `shapes` — формы кончика кисти.

  Кладите туда картинки PNG/JPG/BMP/TIFF/WebP (лучше бесшовные, в оттенках серого: тёмное = больше краски)
  и нажмите *Справка > Перезагрузить текстуры*. Готовые текстуры создаются при первом запуске.
* **Слои**: пиксельные, линейные (векторные, с правкой точек, нажима, толщины и цвета после рисования),
  текстовые (шрифты Windows), корректирующие, папки. 29 режимов наложения, включая SAI Shine/Shade.
  Обтравка (clipping), в том числе на папку целиком, маски слоёв, «сохранять прозрачность», закрепление,
  метки цветом, «пропускать» для папок.
* **Эффекты слоя** (не разрушают рисунок): обводка, тень, размытие по Гауссу в реальном времени,
  наложение цвета, текстура бумаги.
* **Коррекция**: яркость/контраст, тон/насыщенность, уровни, кривые, цветовой баланс, карта градиента,
  инвертирование, обесцвечивание, постеризация, порог, сочность, экспозиция. Можно применить к слою
  или создать корректирующим слоем, который можно поменять в любой момент.
* **Фильтры**: размытие по Гауссу, размытие в движении, контурная резкость, резкость, свечение, шум, пикселизация.
* **Трансформация**: свободная, с перспективой и наклоном, деформация сеткой, пластика (сдвиг, закрутка, сжатие, раздувание).
* **Линейки**: перспектива на 1/2/3 точки с привязкой штрихов, симметрия (зеркала и радиальные копии).
* **Выделение**: прямоугольник, овал, лассо, волшебная палочка, кисть выделения; расширить, сжать, растушевать, рамка.
* **Заливка**, **заливка лассо**, **градиенты** (линейный/радиальный/зеркальный, многоточечные).
* **Холст до 100000 x 100000**, несколько окон одного холста, навигатор, пиксельная сетка, шахматка прозрачности.
* **Восстановление работы**: копия сохраняется в фоне, после сбоя программа предложит восстановить рисунки.
* **Форматы**: свой `.gxp` (все слои и функции), PSD/PSB (слои, папки, маски, обтравка, режимы наложения),
  PNG, JPEG, BMP, TIFF, WebP.
* **Темы**: тёмная, серая, светлая. Русский и английский язык.
* Черновик для смешивания цветов, панель референсов, история действий, палитры `.gpl`.

## Сборка из исходников

Нужны Qt 6.8, CMake 3.21+, компилятор C++20 (MSVC 2022). Готовая сборка делается автоматически
через GitHub Actions (`.github/workflows/build.yml`).

```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=<путь к Qt>
cmake --build build
```
