# GraphiX Paint

Программа для рисования в духе PaintTool SAI 2. В ней тот же нажим и стабилизатор, что в SAI, больше настроек кистей и слои как в Photoshop / Clip Studio. Есть деформация сеткой, пластика, кривые, PSD, лайнарт из любой картинки, заливка по лайнарту и запись видео процесса.

**Скачать для Windows 10/11 (64 бит):**
https://github.com/Ledston/graphix-paint/releases/latest/download/GraphiX-Paint-win64.zip

Распакуйте архив в любую папку (например, `Документы\GraphiX Paint`) и запустите `GraphiX.exe`. Установка не нужна. Если положить рядом с программой пустой файл `portable.txt`, все настройки и кисти будут храниться в папке программы. Так удобно носить её на флешке.

## Планшет (Huion и другие)

По умолчанию программа работает через **Wintab**, как SAI. Поэтому Windows Ink в драйвере планшета можно выключить.

Переключение находится в *Настройки → Ввод с пера*: Wintab или Windows Ink. Оно срабатывает сразу, перезапуск не нужен. Если драйвер Wintab не найден, программа сама работает через Windows Ink.

В *Настройки → Перо и планшет…* есть:
- общая кривая нажима с полем для проверки;
- порог слабого нажима;
- обратный конец пера как ластик;
- боковая кнопка как пипетка;
- нажим для мыши.

## Основное

| Что | Как |
|---|---|
| Двигать холст | Пробел + перетаскивание, средняя кнопка мыши |
| Масштаб | Ctrl + Пробел + перетаскивание, колесо мыши, Ctrl +/- |
| Повернуть холст | Alt + Пробел + перетаскивание, клавиши `-` / `=`, сброс — Backspace |
| Отразить вид | H |
| Проверка в ч/б | Ctrl+Shift+Y |
| Пипетка | Alt (удерживать) или правая кнопка |
| Размер кисти | Ctrl + Alt + перетаскивание, `[` и `]` |
| Ластик / кисть | E |
| Поменять цвета / сбросить | X / D |
| Переместить слой (или все выбранные) | Ctrl (удерживать) + перетаскивание, инструмент V |
| Трансформация / сетка / пластика | Ctrl+T / Ctrl+Shift+T / Ctrl+Shift+X |
| Сделать лайнарт | Ctrl+Shift+L |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |

**Найти любую команду: Ctrl+F.** Начните писать название (по-русски или по-английски), и в списке будет видно, где команда лежит в меню и какая у неё клавиша. Enter — выполнить.

**Все горячие клавиши настраиваются:** *Настройки → Горячие клавиши* (Ctrl+Alt+K). Там есть поиск и проверка конфликтов.

## Слои

- **Несколько слоёв сразу.**
  - Ctrl + щелчок добавляет слой к выбранным или убирает его.
  - Shift + щелчок выбирает все слои подряд.
  - Выбранные слои можно двигать, трансформировать, удалять, дублировать, объединять, складывать в папку и перетаскивать в списке. Видимость, непрозрачность и режим наложения меняются у всех сразу.
- **Двойной щелчок по слою** открывает его свойства. **F2** переименовывает слой.
- **Правый щелчок по слою** открывает меню со всем, что можно сделать со слоем:
  - создать слой;
  - дублировать, объединить, сложить в папку;
  - опорный слой, обтравка, сохранение прозрачности, закрепление, цвет метки;
  - быстрые эффекты;
  - каналы;
  - маска;
  - пиксели.
- **Каналы**:
  - хроматическая аберрация, включается и выключается одним щелчком;
  - альфа → выделение;
  - прозрачность → маска;
  - альфа-канал как слой;
  - инвертировать альфу;
  - разложить на красный, зелёный и синий слои;
  - убрать белый фон (для сканов);
  - перекрасить в основной цвет.
- **Эффекты слоя** не портят рисунок и меняются в любой момент:
  - обводка (гладкая);
  - тень и внутренняя тень;
  - внешнее и внутреннее свечение;
  - наложение цвета и градиента;
  - размытие;
  - текстура бумаги;
  - зерно (шум);
  - скринтон;
  - хроматическая аберрация.
- 30 режимов наложения, включая SAI Shine / Shade и «Затухание (шум)».
- Слои бывают пиксельные, линейные (векторные), текстовые, корректирующие и папки. Обтравку можно ставить и на папку.

## Лайнарт и покраска

- **Фильтр → Сделать лайнарт…** превращает любую картинку в настоящий лайнарт: линии на прозрачном слое, под которым можно красить. Есть живой предпросмотр.
  - Режимы: авто, фото, набросок / скан, аниме / рендер.
  - Настройки линий: детализация, толщина, плавность, удаление соринок, закрытие разрывов, цвет линий.
  - «Как от руки»: дрожание, нажим, вторая скетчевая линия, текстуры карандаша, угля и туши.
  - Готовые шаблоны.
  - Результат можно сделать редактируемым слоем линий.
- **Заливка обводкой** (инструмент F, режим «Залить замкнутые области внутри»): обведите примерно то, что нужно покрасить. Каждая область лайнарта, которая в основном внутри, заливается до линий и под них, без белых щелей.
- **Заливка по лайнарту.** Отметьте слой с линиями как *опорный* (правый щелчок → «Опорный слой»), у заливки выберите «Границы: опорные слои» и заливайте на слое под линиями. Настройки «Закрывать щели» и «Заходить под линии» убирают белые края.
- **Слой → Автозаливка цветами** заливает каждую замкнутую область лайнарта своим цветом на отдельном слое.

## Материалы

**Окно → Материалы** — панель с готовыми вещами. Любую можно перетащить на холст или открыть двойным щелчком:
- **Картинки** — свои картинки и кусочки рисунков: кнопка «Сохранить выделенную часть слоя как картинку». Картинка встаёт новым слоем там, куда её бросили.
- **Узоры** — шахматка, полоски, горошек, клетка, шотландка, сердечки, звёзды, зигзаг, волны, чешуя, ёлочка… Узор заливает выделение (или всю картинку) на новом слое. Свой узор — «Сохранить выделенную часть слоя как узор» или картинка в папке `materials/patterns`.
- **Тона** — скринтоны (точки, линии, квадраты, с переходом). Ложатся слоем тона, который потом настраивается в «Слой → Эффекты».
- **Градиенты** — наборы карт градиента (тёплый вечер, холодная ночь, сепия, кино, неон…). Добавляют слой карты градиента. Свою карту можно сохранить из выбранного слоя карты градиента.

Узоры работают и в заливке: у **заливки** и **заливки обводкой** есть «Заливать узором» (размер узора, своим цветом или цветом узора). В меню **Правка** — «Залить узором» (Alt+Shift+Backspace) и «Обвести выделение…» (ширина, внутри / по краю / снаружи, цветом или узором).

## Остальное

- **Кисти как в SAI**: плотность, жёсткость, смешивание, разбавление, удержание цвета, кайма, нажим на размер, плотность и смешивание.
  - Сверх SAI: форма кончика, наклон пера, разброс, сужение концов, аэрограф.
  - **Штриховка (hatching)**: один мазок рисует пучок линий — их число, толщина, разброс, «как от руки». Часть линий может быть вторым цветом, например белые линии. Есть вариант-смешиватель, который тянет цвета под собой, как палец.
  - **Точки (пунктир)** и **блёстки**, **второй цвет** у любой кисти (задний цвет на панели «Цвет», X меняет цвета).
  - **Текстура кисти**: размер, плотность и сила, а ещё «текстура вдоль мазка» (штрихи, щетина).
  - **Декор**: кисти-ленты (кружево, цепочка, сетка, шов, бусы, верёвка, кирпич, черепица) — узор тянется и гнётся вдоль мазка во всю ширину кисти; кисти-штампы (листья, цветы, звёзды, облака, трава, снежинки, пузыри) — каждый отпечаток случайная картинка набора со своим размером, поворотом и оттенком. Свои штампы — папка с картинками в `textures/stamps`, свои ленты — картинки в `textures/ribbons`.
  - **Фоны**: листва, куст, дождь, снег, мех, пряди волос, пыль, кирпичная стена.
  - Около 50 готовых кистей во вкладках: Основные, Краска, Штриховка, Эффекты, Декор, Фоны, Ластики. В каждой ячейке маленький образец мазка. Свои вкладки, экспорт и импорт.
  - **Двойной щелчок по кисти** открывает окно всех настроек с живым превью мазка и листом, на котором кисть можно попробовать пером. «Отмена» возвращает кисть как была.
- **Стабилизатор**: Среднее (1–15, как в SAI), Скорость (S-уровни), Верёвка, сглаживание нажима.
- **Текстуры как в SAI 2**: *Справка → Открыть папку текстур*. Внутри папки:
  - `paper` — бумага;
  - `brush` — текстуры кисти;
  - `shapes` — формы кончика;
  - `ribbons` — узоры для кистей-лент;
  - `stamps` — наборы штампов (каждая папка — один набор).

  Положите туда картинки и выберите *Справка → Перезагрузить текстуры*.
- **Коррекция**: кривые, уровни, яркость / контраст, тон / насыщенность, цветовой баланс, карта градиента и другие. Её можно применить к слою или сделать корректирующим слоем.
- **Фильтры**: размытие, контурная резкость, свечение, шум (с режимами наложения и размером зерна), пикселизация, скринтон.
  - **Фильтр → Эффекты**: хроматическая аберрация, обводка, тень, свечения, наложение цвета и градиента, текстура бумаги. Ползунки, живой предпросмотр на холсте, применяется по «ОК» прямо в пиксели. С выделением — только внутри него.
- **Трансформация**: свободная, с перспективой и наклоном. Деформация сеткой, пластика.
- **Линейки** (кнопка с линейкой на верхней панели; стрелка рядом выбирает вид): прямая, кривая, эллипс, концентрическая (мазок идёт по овалу, на котором начат), параллельные линии, веер (лучи из точки). Кнопка включает и выключает «вести мазки по линейке». Форма и место меняются инструментом «Линейки» (U): тяните квадратные ручки (Shift — шаг 45° / круг) или саму линию. Линейка сохраняется в файле .gxp. Там же — перспектива и симметрия.
- **Линии концентрации и скорости** (два инструмента рядом с текстом). Линии концентрации: тяните от центра наружу, овал в середине останется пустым. Линии скорости: тяните в сторону движения. Линии рисуются на новом слое основным цветом, а при выделении — только внутри него. Пока такой слой выбран, ползунки меняют его: число линий, толщина и её разброс, неровные концы и промежутки, просветы, размер пустой середины / длина и направление, «Перемешать». Если по слою порисовать, линии становятся обычными пикселями.
- **Выделение**: прямоугольник, овал, лассо, волшебная палочка, кисть, цветовой диапазон. Shift добавляет, Ctrl (или Alt) вычитает, Shift+Ctrl — пересечение. Квадрат / круг — Shift, нажатый уже во время рисования рамки.
  - Волшебная палочка: допуск, «по всем слоям / текущему / опорным», «закрывать щели», «расширить» (заходит под мягкий край линий).
  - Выделение кистью рисует ровно кружком курсора (нажим на размер — по галочке), Ctrl или Alt стирают, а выделенное подсвечивается цветом.
- **Панели**: стрелка на заголовке сворачивает панель; линии между панелями тянутся, и панель любого размера прокручивается. Панель кистей отделена перетаскиваемой линией от настроек и прокручивается. *Настройки → Интерфейс*: какие панели, инструменты, вкладки кистей и материалов и части панели «Цвет» показывать, и «Сбросить интерфейс» (также в меню «Окно»).
- **Вид**:
  - сетка, правило третей, золотое сечение;
  - проверка в ч/б;
  - панель «Превью»: вся картинка целиком, с отражением;
  - гармонии цветов на панели «Цвет».
- **Запись видео** (кнопки ● ❚❚ ■ на верхней панели или *Файл → Запись видео*):
  - ● — начать или продолжить запись, ❚❚ — пауза, ■ — стоп. После «Стоп» выбираете скорость (реальная или «ускорить до N секунд») и куда сохранить MP4.
  - F9 — запись / пауза, Shift+F9 — стоп и сохранить (клавиши меняются в настройках).
  - Пока идёт запись, внизу горит красный «● REC 00:12:34», а в заголовке окна — «● REC». На паузе там видно «❚❚ Пауза» и сколько уже записано.
  - Что записывать — выбирается стрелкой у кнопки ●: только холст (одна картинка, без панелей) или всё окно программы.
  - Записывается только время, когда вы рисуете: если ничего не меняется, видео ждёт.
  - Запись на паузе хранится между запусками. Откройте тот же файл и нажмите ●, чтобы продолжить.
  - Любой слой можно убрать из записи: правый щелчок по слою → «Не показывать в записи» (или в свойствах слоя). Пока вы рисуете, слой виден как обычно, а в видео его нет. Так подложки, обводимые картинки и вспомогательные слои не попадают в запись.
- **Референс поверх всего** (*Вид → Референс поверх всего*, Ctrl+Alt+R), как в «すけふれーむ»:
  - картинка с панели «Референс» висит прозрачным окном над холстом (и над любой другой программой);
  - непрозрачность меняется ползунком или Ctrl + колесо, колесо меняет размер, окно можно двигать и тянуть за края, есть ч/б и отражение;
  - «Рисовать сквозь референс» (Ctrl+Alt+D): перо проходит сквозь картинку прямо на холст;
  - **картинку не видно в записи экрана, на стримах и при показе экрана** (OBS, Discord, Zoom и т. п.). Зрители видят только холст. Нужна Windows 10 версии 2004 или новее; на более старой Windows вместо картинки в записи будет чёрный прямоугольник.
- **Холст до 100000 x 100000**, несколько окон одного холста, восстановление работы после сбоя.
- **Форматы**:
  - `.gxp` — всё сохраняется;
  - PSD / PSB — слои, папки, маски, обтравка, режимы;
  - PNG, JPEG, BMP, TIFF, WebP.
- **Настройки** (меню *Настройки*): язык (русский / English), темы (тёмная, серая, светлая), размер значков, курсор, холст, перо, файлы, производительность.

## Сборка из исходников

Нужны Qt 6.8, CMake 3.21+ и компилятор C++20 (MSVC 2022). Готовая сборка делается автоматически через GitHub Actions (`.github/workflows/build.yml`).

```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=<путь к Qt>
cmake --build build
```
